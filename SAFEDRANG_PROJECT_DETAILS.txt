1. EXECUTIVE SUMMARY & BRAND IDENTITY
--------------------------------------------------------------------------------
Safed Rang is a direct-to-consumer (D2C) luxury handloom and couture e-commerce brand
specializing in authentic Awadh Chikankari, Royal Zardozi, Mukaish, Kamdani, and Tepchi
artistry from Lucknow, Uttar Pradesh, India.

Core Brand Pillars:
- "The One-of-One Edit": Rare, mastercrafted individual sarees where each piece
  features a unique combination of fabric, dye, embroidery, and embellishment. Once
  sold, the design is retired permanently and archived.
- Repeatable Luxury Lines: Handcrafted Kurta Sets, Viscose/Chanderi Dupattas, and
  Custom-fit Blouses with variable sizing (36 to 44 / XS to XXL).
- Slow Fashion & Heritage: Bypassing industrial machine embroidery; every creation
  is hand-stitched by generational karigars in the historic lanes of Chowk, Lucknow.

Visual & Design Aesthetics:
- Deep Royal Wine / Crimson: #6E1E2A (featured boxes, accents, primary emphasis)
- Antique Champagne Gold: #AE8A54, #C9A876 (buttons, borders, icons, highlights)
- Warm Studio Beige / Ivory: #FAF5EC, #F5EFEB, #ECDCCF (warm editorial background)
- Deep Charcoal / Black: #2A211D, #1A1412 (typography, luxury headers)
- Pure White: #FFFFFF (cards, clean surfaces)
- Typography:
  - Headings: Editorial serif ("Playfair Display", "Cormorant Garamond", "Cinzel")
  - Body & UI: Modern legible sans-serif ("Manrope", "Inter", -apple-system)
  - Style: Subtle uppercase letter-spacing, elegant borders (1px gold tinted),
    zero generic "drop shadows", high-contrast editorial photography.

4. DATA MODELS & INVENTORY LOGIC
--------------------------------------------------------------------------------
A. Product Entity Structure:
{
  id: "SR-101",                      // String or number unique identifier
  name: "CHANDERI CHIKANKARI SAREE", // Full product title (uppercase in display)
  sku: "TFM110044",                  // Stock Keeping Unit
  price: 14499,                      // Current selling price (INR)
  regularPrice: 16999,               // MRP / Original price (optional for sale strike)
  salePrice: 14499,                  // Discounted price
  category: "Sarees",                // Sarees | Kurta Sets | Dupattas | Blouses | Others
  stock: 2,                          // Inventory quantity (default 2 across catalog)
  isOneOfOne: false,                 // Boolean: exclusive single-piece flag
  productType: "simple",             // "simple" or "variable"
  variations: [                      // Used when productType === "variable" (e.g. Blouses/Kurtas)
    { size: "38", price: 2000, stock: 2, sku: "BB-0425M-38" },
    { size: "40", price: 2000, stock: 2, sku: "BB-0425M-40" }
  ],
  images: [                          // Array of image paths/URLs
    "/woman_chikankari_saree.jpg",
    "/pdp-2.jpg"
  ],
  description: "Handcrafted Lucknow Chanderi silk saree with intricate Chikankari...",
  craft: "Chikankari & Zardozi",     // Craft technique filter
  fabric: "Pure Chanderi Silk",      // Fabric material filter
  colour: "Ruby Red",                // Color family
  status: "In Stock"                 // Auto-derived: "Out of Stock" if stock <= 0
}

B. Out-of-Stock Logic:
- When `stock === 0`:
  - `ProductCard.jsx` displays a soft red "Out of Stock" pill.
  - `ProductDetail.jsx` disables the "ADD TO BAG" and "BUY NOW" buttons with text "SOLD OUT".
  - Variable products disable specific size chips when variant stock is 0.

C. Categories Sync:
- Categories are defined with standard IDs and slugs:
  `Dupattas`, `Sarees`, `Kurta Sets`, `Blouses`, `Others`.
- In `Categories.jsx`, the "Products" count column is dynamically calculated in
  real time by counting all active products in `ProductContext` matching the category name.
- Fuzzy matching in `Shop.jsx` ensures singular/plural variants ("Dupatta" vs "Dupattas")
  both display the correct products.

7. GUIDELINES FOR PROMPTING THE CURRENT AI AGENT
--------------------------------------------------------------------------------
When using another AI to write prompts for this coding agent, follow these instructions
for maximum efficiency, zero hallucinations, and high-accuracy code:

1. Always specify exact file paths:
   - Good: "In `frontend/src/pages/ProductDetail.jsx` and `ProductDetail.css`, ..."
   - Bad: "On the product page, update..."

2. Respect the Visual Identity:
   - Do NOT introduce generic purple, bright neon colors, or default Bootstrap styles.
   - Use existing CSS variables:
     `--color-wine: #6E1E2A;`
     `--color-antique-gold: #AE8A54;`
     `--color-warm-beige: #FAF5EC;`
     `--color-dark-charcoal: #2A211D;`
   - All headings must use serif editorial styling; buttons should use uppercase with
     slight letter spacing.

3. Windows OS & PowerShell Awareness:
   - The agent runs on Windows with PowerShell.
   - Commands should use Windows/PowerShell syntax (e.g. forward slashes for node paths,
     `Get-Content`, `npm run build`, etc.).
   - When modifying files, prefer contiguous drop-in replacements or python helper
     scripts to preserve correct line endings (LF/CRLF).

4. Preserve State & Build Health:
   - Never break `ProductContext.jsx` or reset `stock` unexpectedly.
   - Always instruct the agent to run `npm run build` inside `frontend` to verify
     that TypeScript/JSX syntax compiles cleanly before concluding a task.
   - Remind the agent to commit and push changes to `main` when requested.
